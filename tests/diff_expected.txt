# Cases that differ from Linux on purpose: name, then why, with a reference.
buffer_lifetime A new anonymous mapping over a registered buffer can share its pages: FreeBSD keeps a held page in its memory object when the range is unmapped, and a mapping that extends that object maps the page again, zeroed. Linux pins pages apart from any mapping. After munmap(2) alone both keep using the pages (docs/held-buffers.md, What the implementation changed).
poll_hup The poll result follows the file: a pipe closed by its writer gives POLLIN|POLLHUP from poll(2) on FreeBSD and POLLHUP on Linux. native_in shows it (Platform).
newer What Linux 7.3 has past IORING_OP_PIPE is refused here (COMPATIBILITY.MD, rows marked Unsupported).
ext_arg_order kqring checks an enter's wait argument before it submits anything, so a bad one fails the enter; Linux submits first and returns the count (COMPATIBILITY.MD, IORING_ENTER_EXT_ARG).
exit_armed When a process exits, kqring completes its requests in flight with -ECANCELED at once; Linux cancels at exit only requests on io_uring files and ends the others when they would next run, here when the pipe becomes readable (docs/concurrent-submitters.md, Exit).
